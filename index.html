Vanilla JavaScript · Architecture showcase

Small product, explicit boundaries

A neon arcade Pong with no framework, no game engine and no runtime dependency, so every engineering decision stays visible.

  • Domain Scoring, collisions, spin and the computer opponent. Deterministic and browser-free.
  • Application The match state machine, a fixed-timestep loop, and events that drive sound, vibration and effects.
  • Adapters Canvas rendering, WebAudio, touch and keyboard input, and the interface around the board.
